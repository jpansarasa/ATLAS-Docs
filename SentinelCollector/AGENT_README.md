# SentinelCollector — architecture [agent read-first]

NOTE: this card covers the news->matrix pipeline which spans SentinelCollector AND MacroSubstrate (see MacroSubstrate/README for the shared write path).

PURPOSE: news-article -> `(signal x sector)` matrix tilt via GPU vLLM JSON-CoD extraction (Extraction:Backend=VllmJson, Gemma 4 31B QAT w4a16 @ vLLM 0.28.0 -- the SCORED coordinate, D-29) + `:sig:` rows in macro_observations. CoD is only as trustworthy as CoVE: tier 1 (every extracted fact checked against its source before it can become a row or be attached) is IN scope and is D-35; tier 2 (the semantic tier, design §7.2: does each published figure describe the instrument it is HELD on) runs on every publishable row before persist and clears only what it measures wrong, D-36. no gRPC cell push; the digest and the legacy v1 extraction path are not addressed here. (CPU llama-server DSL extraction = rollback path.)

DATA MODEL + INVARIANTS:
  INV `:sig:` infix: news row identified SOLELY by literal `:sig:` in source_id (`{rawContentId}:sig:{signalId}`). not schema-enforced — string contract; FOUR artefacts move together: producer (MacroObservationRouter) + projector const (ObservationCellProjector) + consumer (NewsMomentumQueryService) + digest reader (DigestQueryService.ArticleSignalsSql + TryParseRawContentId). change-all-or-none.
  INV signal⊥sector: signal_identity_id=SIGNAL dim gates projection; atlas_sector_code=SECTOR dim does NOT gate. null-signal->never projects (qualitative rows skipped permanently).
  INV |v|<=1: `:sig:` rows carry |value|~<=1; projector excludes |v|>1.5 (raw-value leak guard); drops non-`:sig:` rows from decay sum even if same group (G2 mixed-group drop).
  INV heal-on-rewrite: macro_observations = authoritative cell source; projector re-projects in place (DO UPDATE), never DO NOTHING.
  INV sector-dim⊥entry: resolve-entities sectorless/fail -> row still written (sector=null or fallback); prepass feeds sector-pick inside classify, not an entry gate.
  INV incomplete-SectorWeights: group whose pattern's SectorWeights missing any sector -> ArgumentException caught -> group skipped, 0 cells, logged Warning not Error.
  INV decay: news magnitude = K*tanh(S/K) over half-life-weighted decay sum (freshness=1.0, no floor). K+H from Matrix:NewsDecay. Not the hard-data mean formula.
  review_status AutoClosed = terminal NoResolution disposition (Stage 1): NoResolution rows never auto-approve/reject -> would pile up Pending forever. AutoClosed exits the human queue (ReviewUiEndpoints query = Pending AND InstrumentId!=null AND ResolutionState==Resolved — NoResolution rows are excluded from the human view by the ResolutionState==Resolved filter whether or not they carry a stray instrument_id, see review-UI GOTCHA; AutoClose = the terminal/digest transition) while the digest KEEPS it (DigestQueryService !=Rejected; NOT Rejected — that would strip legit macro/qualitative digest content). Set by NoResolutionSweepWorker (age-gated, NoResolutionCloseGraceDays default 7) + POST /admin/review/close-noresolution. No D-entry — terminal-state janitor, not an exception path.

PATHS (distinct code — do not conflate):
  NewsSignalClassifier [in-proc · inside ExtractionProcessor]
    does: structured vLLM call; inlines signal_identities catalog + 11 sector codes; validates ids; drops <0.5 confidence / NaN / hallucinated.
    does NOT: throw (fail-soft->Empty); parse free-form; touch DB.
    on-miss: empty catalog / empty excerpt / timeout / unstructured -> NewsSignalClassification.Empty; extraction proceeds.
    ⚠ excerpt capped before call — signal in tail -> Empty, not failure. Sub-floor confidence empties feed silently (counted, not errored).
  MacroObservationRouter writer [in-proc · MacroSubstrate]
    does: upsert value_numeric=tilt*confidence; source_collector="sentinel"; `:sig:` source_id.
    does NOT (NEWS caller): fall back to extracted_observations — Failed=row LOST (by design); count IdempotentSkip as progress.
    ⚠ CollectedAt stored as UTC instant of its offset, not source wall-clock; matters for idem-key matching.
    ⚠ NUMERIC caller DOES fall back to extracted_observations two-phase. Fallback behavior diverges by CALLER not method.
  ObservationCellProjector [ThresholdEngine background · DB-poll]
    does: read Kind=Numeric DESC; group by (signal_identity_id,source_collector) -> 11 sector rows/group; decay sum -> K*tanh(S/K) * trust * temporal * confidence * sectorWeight clamped +/-3; upsert matrix_cells.
    does NOT: gate on sector; project null-signal rows; project unknown/disabled patterns; write partial cell-set for incomplete SectorWeights.
    does not run when Matrix:ObservationProjectorMode=Off -> zero matrix_cells + no error. CHECK this config FIRST before concluding pipeline broken.
    ⚠ Shadow is not dry-run: runs identical read+project+write as Authoritative (same cells written); only Off suppresses writes.
    ⚠ read DESC + hard cap -> sustained ingest silently drops oldest (cap-induced staleness, metered).

  KnownPublisherSources / DeterministicResolver Rule 0 [in-proc · v2 resolve stage · D-32]
    does: on a registered source (challenger-rss) attach the owned series (CHALLENGER_JOB_CUTS) by provenance when the row's source_entity is the owner surface ("Challenger job cuts"); refuse every other attachment on that source (source_no_owner); clear an owned row whose value is off the series' scale (source_value_implausible) then deny all when >1 owned row remains (source_ambiguous); date the owned row by the month the report MEASURES (PeriodEnd from the headline quote or URL slug) or clear it (source_report_period_unknown); count each REPORT document as owned_key_attached|no_owned_key|not_extracted, keyed on PUBLISH; on a SecMaster outage during Rule 0 fail the ARTICLE (D-27 post-model branch, tagged dependency_unavailable_after_extraction, counted not_extracted) so a reprocess re-runs the whole path.
    does NOT: run any resolver leg or the paid rung on a registered source; leave an outage as a Pending owned row (nothing that revisits Pending can publish it); let the re-extract sweep re-resolve one (source_reextract_skipped); date the point by ingest or release time; cover publishers that arrive on general news (ADP, Indeed, Redbook, Truflation); scope the catalog; skip EntityResolutionPrepass (it still runs, unread); count a document that dies on an exception.
    on-miss: owner surface absent from the row's own source_entity slot (the lede-ENT fallback is NOT consulted on a registered source) OR from entities[] (D-15 discards an undeclared one) -> the headline reads source_no_owner and the report counts no_owned_key -> SentinelKnownSourceReportUnattached the same day. No month in the headline or URL -> source_report_period_unknown, same alert.
    ⚠ everything here rides the v2 JSON path: a registered source with UseV2Pipeline off or missing from Extraction__V2EnabledSources loses Rule 0, the guards, the addendum AND the detector at once; the LlamaServerDsl backend loses the addendum alone (boot Warning for each; compose template pinned by test).
    ⚠ the addendum lives at cod-prompts/sources/{source}.txt and ships through the same host mount as the master prompt; if the mount is stale the model never sees the owner surface and every report reads no_owned_key.

PROCESSING ORDER (per article): normalize -> EntityResolutionPrepass(spaCy NER->SecMaster,fail-soft) -> V2 pipeline -> TryClassifyNewsSignalsAsync -> per-signal preferredSector=grounded??classifier.Sector -> plan -> write -> addRange.
MAXIM: prepass output FEEDS classify as parameter -> router derives grounded sector. Prepass=sector input, not an entry gate.

DISTINCTIONS:
  `:sig:` news row ≠ raw-legacy sentinel row — same table/group; only `:sig:` feeds projector decay sum; legacy raw values dropped (G2).
  signal-dim (signal_identity_id, gates projection) ≠ sector-dim (atlas_sector_code, does NOT gate).
  matrix feed (macro_observations->projector->matrix_cells) ≠ digest consumer (matrix_cells+sector_regimes+sentinel rows, separate read; theme taxonomy retired — sector is the only digest axis) ≠ extracted_observations (legacy numeric fallback sink, not read by matrix or digest).
  digest news-momentum SQL filters source_collector='sentinel' AND signal_identity_id IS NOT NULL AND value_numeric BETWEEN -1.5 AND 1.5 — not a `:sig:` infix filter; splits window at midpoint for early->late per-signal tilt trend (replaces former bias-vs-FRED-matrix view, removed: FRED matrix too stale/sparse -> fake divergence). Legacy non-`:sig:` sentinel numeric rows WITH signal_identity_id enter digest momentum avg but ARE dropped by projector (G2). Two consumers see DIFFERENT effective inputs.
  news magnitude=decay-weighted SUM(K*tanh(S/K)) ≠ hard-data mean(sum(o_i)/n * freshness scalar). Unexpected news cell magnitude -> CHECK Matrix:NewsDecay K/H.
  ThresholdEngine projector(DB-polled) ≠ gRPC MatrixUpdateStream/ObservationEventStream (separate event surface; matrix feed is DB-polled not gRPC).

CROSS-SERVICE:
  IN: SecMaster HTTP :8080 /api/signal-identities (catalog warmup) + /api/resolve-entities (sector grounding, fail-soft). vLLM GPU (classify).
  IN: ThresholdEngine gRPC-stream :5001 ObservationEventStream (ValidationEventConsumerWorker — sector-crossing events -> validation triggers).
  OUT: macro_observations via in-proc DI, not network. FEEDS: ThresholdEngine projector (DB-poll) -> matrix_cells; digest reads matrix_cells separately.
  EXPOSES gRPC :5001: ObservationEventStream (ThresholdEngine consumes) + SecMaster gRPC :5001 RegisterSeries (f-a-f on extracted observations).
